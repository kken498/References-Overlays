# [Blender Extensions](https://extensions.blender.org/add-ons/references-overlays/)

# PureRef for Blender!!! 
You can add references in the 3D Viewport Overlays

### ⭐ Credit
Thanks for new feature overhaul contributed by [hced](https://github.com/hced/References-Overlays)

# Features
* Add images or video references directly in the 3D viewport.
* Drag the references directly.
* Enable an option to switch it on or off at your convenience.
* Independent screen workflow.
* Allow transformations and flipping of the references.
* Set the opacity of the references.
* Change the layer orders of the references.
* Utilize the color picker on the references.
* Set the references depth.
* Multiple media support (Video, GIF, etc).
* Cropping the references.
* Support Grayscale mode.
* Support orthographic alignment display
* Paste the image from the clipboard.

# Location
* View 3D > Header

# ⌨️ Hotkey
* `Alt+Shift+R`: Toggle References Overlays
* `Ctrl + T`: Toggle References Overlays Locked
* `Shift + V`: Paste from the clipboard 
* `Ctrl + W`: Global Move References 

### References Moving Modal Keymap
![Image](https://i.imgur.com/tsufFcY.gif)

| Action | New Key |
|---|---|
| **Confirm** | `LMB` |
| **Cancel** | `RMB` |
| **Rotate** | `R` + Drag (circular) |
| **Scale** | `S` + Drag / Scroll Wheel |
| **Zoom** | `Z` + Drag |
| **Alpha/Opacity** | `A` + Drag |
| **Crop** | `C` + Drag |
| **Pan** | `G` + Drag |
| **Grayscale Toggle** | `B` |
| **Position Lock** | `L` |
| **Only Orthographic** | `O` |
| **Flip X / Y** | `F` / `V` |
| **Set Depth** | `1`(Default) / `2`(Back)|
| **Snap** | `Ctrl` |
| **Remove** | `X` or `Del` |

**Quick Resets (Alt + Key):**
* `Alt+R`: Reset Rotation
* `Alt+S`: Reset Scale
* `Alt+Z`: Reset Zoom
* `Alt+A`: Reset Alpha
* `Alt+C`: Reset Crop
* `Alt+G`: Reset Pan/Pivot

**Other:**
* **Orthographic (`O`):** Auto-detects the closest (to camera view) orthographic view and toggles an *ortho-only* filter for the image.
* **Hide/Isolate:** `H` hides the current image, `Shift+H` isolates it (hides all others), `Alt+H` unhides all.
